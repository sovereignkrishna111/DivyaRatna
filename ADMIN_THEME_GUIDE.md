# 🎨 Website Theme Manager - Admin Quick Guide

## For Non-Technical Admins: Change Your Website Colors in 5 Minutes

### ✨ What This Does
With this theme manager, you can **change every color on your entire website** with just a few clicks. No technical skills needed!

---

## 🚀 Quick Start: Change Your Website Colors

### Step 1: Go to Theme Manager
1. Login to your Admin Panel
2. Click **"Theme & Media"** in the left sidebar
3. Click the **"Colors"** tab

**You're now in the Theme Manager!** ✅

---

### Step 2: Choose What to Change
On the left side, you'll see different color categories:

| Category | What It Controls |
|----------|-----------------|
| **Primary Colors** | Main brand colors (Maroon) |
| **Secondary Colors** | Alternative brand colors |
| **Accent Colors** | Gold/Amber highlights |
| **Backgrounds** | Page & section backgrounds |
| **Text Colors** | All text on the site |
| **Buttons** | All button colors |
| **Borders** | Lines & dividers |
| **Status Colors** | Success, Error, Warning messages |

**Click any category** to see the colors you can change.

---

### Step 3: Pick Your New Colors

For each color you want to change:

1. **Click the color square** to open the color picker
2. **Pick a color** you like (just like in Paint!)
3. **Or type a hex code** if you have one (e.g., `#991b1b`)

```
┌─ Color Picker Square (click to open color chooser)
│
│  Color Code Input ──────► Type here or paste hex codes
│  
└─ Preview Square (shows how it will look)
```

---

### Step 4: See It Live
As you change colors, **watch the preview below** - you'll see buttons, backgrounds, and text update in real-time!

---

### Step 5: Save Your Changes
Click the **"Save All Changes"** button at the top right.

**That's it!** ✅ Your website will change immediately!

## 🎯 Real-World Examples

### Example 1: Change Brand Color from Maroon to Blue
1. Click **Primary Colors** on the left
2. Find **"primary-800"** (the darkest one)
3. Click the color square
4. Pick a nice blue
5. Click **"Save All Changes"**
6. Visit your website - everything is now blue! ✨

### Example 2: Make Gold Buttons Brighter
1. Click **Accent Colors**
2. Find **"accent-500"** (the main accent color)
3. Pick a brighter gold
4. Save!

### Example 3: Change Text Color
1. Click **Text Colors**
2. Find **"text-primary"**
3. Change to your preferred text color
4. Save!

## ❓ FAQ - Common Questions

### Q: Will my changes apply immediately?
**A:** Yes! After you click "Save All Changes", the website updates instantly. No need to refresh or restart anything.

### Q: Can I go back if I mess up?
**A:** Absolutely! Just change the colors back and save again. There's also a "Reset to Defaults" button that returns everything to the original design.

### Q: What if I don't know hex codes?
**A:** No problem! Use the **color picker** (the colorful square) to pick colors visually. It works just like any drawing program.

### Q: Which colors affect which parts?
**A:** Here's the breakdown:
- **Primary Colors** = Headers, main buttons, borders
- **Secondary Colors** = Alternative buttons, accents
- **Accent Colors** = Special CTAs, highlights, badges
- **Text Colors** = All writing on the site
- **Backgrounds** = Page and section backgrounds
- **Buttons** = Every clickable button color

### Q: I changed Primary Color but some things didn't change?
**A:** If you notice some colors didn't update completely, it means:
1. Refresh your browser (F5)
2. Clear your browser cache
3. Try a different browser
4. Contact technical support

This usually fixes it!

## 💡 Pro Tips

1. **Take a screenshot** of your current design before making big changes
2. **Change one color at a time** so you can see what each does
3. **Ask colleagues** for feedback before saving final changes
4. **Test on mobile** - click different device sizes to ensure colors look good everywhere
5. **Use the preview area** to see how buttons, text, and backgrounds look with your new colors

## 📞 Need Help?

If something goes wrong:
1. Try clicking "Reset to Defaults" to restore original colors
2. Refresh your browser
3. Contact the technical support team with details of what you tried
